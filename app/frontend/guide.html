开始使用BOSS 连接关于项目

按一个真实机会开始

  1. 收集岗位。在找岗位中手动添加岗位详情，或按需连接 BOSS 读取。
  2. 准备简历。查看匹配依据，复用已有方向或复制岗位专属版本，编辑后预览并导出 PDF。
  3. 本人投递。在招聘原页面发送简历或联系招聘者，回来记录实际进度。
  4. 继续跟进。安排笔试、面试和 DDL；拿到薪酬方案后比较税后收入。

BOSS 连接说明

可选连接。未连接时，手动添加岗位详情、简历、日历和薪酬功能均可使用。

1. 准备本机工具

需要 Google Chrome 和 boss-agent-cli。后者帮助工作台读取你已登录的 BOSS 网页；它是社区工具，并非 BOSS 官方接口。

先点击「检查本机工具」。如果显示已安装，可直接进入第 2 步。

尚未检查。此检查只读取本机工具状态，不访问招聘账号。

未安装？展开安装方法
  1. 安装 Google Chrome。
  2. 按 uv 官方安装说明安装 uv，安装后重新打开终端。
  3. 在终端粘贴下方命令，按回车。macOS 用「终端」，Windows 用 PowerShell，Linux 用 Terminal。
uv tool install --python 3.12 "boss-agent-cli==3.0.1"

完成后输入 boss --version。如提示找不到命令，运行 uv tool update-shell，重新打开终端，并重启工作台服务。

2. 打开专用 Chrome 窗口

普通 Chrome 窗口不能直接连接。专用窗口有独立的登录资料，不会使用你日常浏览器的登录状态。

命令只复制到剪贴板。请粘贴至对应终端后自行执行。端口仅限本机 127.0.0.1，请勿改为对外开放。


3. 在官方页面完成登录
  1. 在新打开的专用 Chrome 中进入 BOSS 官方页面。
  2. 自行扫码或输入账号完成登录；验证码也在该页面处理。
  3. 保持这个窗口和 BOSS 标签页打开，再回到求职工作台。
工作台不会索取或代填密码、短信码，也不会替你操作验证。


4. 回到「找岗位」验证连接
选择关键词与城市，点击搜索。成功显示真实岗位后，才说明这一次连接读取成功。仅显示「CLI 已安装」不能说明你已经登录。

每次搜索由你手动发起。需要重新登录时，回到专用 Chrome 处理；遇到风险停止时，先按下方排障指南处理，不要连续重试。


网页正常，为什么仍提示“平台风险停止”？


工作台通过社区 CLI 读取接口。网页能打开、甚至能看到岗位，不等于这一刻的接口请求也会通过平台检查。风险提示需要区分两层：


  • 平台拒绝了本次请求：例如 ENVIRONMENT_RISK，表示接口返回环境风险；可能涉及会话状态、请求环境或接口兼容性，不能仅凭这个错误断定账号被封或 CLI 代码有问题。
  • 本机保留了上次风险锁：CLI 会记录风险并阻止后续请求；工作台也会在当前运行期间停止读取。因此网页恢复后，本机仍可能显示“已停止”，这不一定是又发出了一次请求。


最近一次在线排查：2026-11-21，官方页面恢复、经授权解除本地锁后，产品经理第 2 页仍返回环境风险（平台 code 37）。已停止验证，尚未确认上游原因。第 2 页及 AI 岗位薪资未完成在线验收。


按顺序恢复，只做一次验证


  1. 先停止点击搜索。在第 2 步启动的专用 Chrome 中，手动确认登录，搜索相同关键词和城市，并查看下一页与薪资。如果官方页面也有验证或异常，先按平台提示处理。
    2. 

  2. 检查本机工具。上方“检查本机工具”只读取安装和风险锁状态，不访问招聘平台。检查版本是否为本工作台已适配的 3.0.1；记录错误码、发生时间与搜索条件。
    3. 

  3. 仅在官方目标页面确已恢复后，显式解除本地锁。在终端执行下方命令。它会清除本地风险锁，也可能清理 CLI 的过期缓存；不会解除服务器限制，不代表搜索已经恢复。


boss clean --risk-lock


  1. 重启工作台服务。在原来运行工作台的终端按 Ctrl+C，再使用原启动方式启动；macOS 可重新双击“打开简历工作台.command”。仅刷新网页无法清除工作台当前进程的停止状态。
    2. 

  2. 只验证一个关键词、一座城市、一页。若再次出现风险，请停止并保留新的风险锁，不要反复清锁重试。暂时在官方网页找岗位，再手动添加岗位详情到工作台。


怀疑 CLI 兼容性问题时


用 boss --version 核对版本，并查阅 上游问题列表。反馈时提供版本、操作系统、错误码和去除个人信息后的复现步骤；不要上传 Cookie、登录资料或完整浏览器目录。升级前先确认上游修复说明，升级后仍需有限验证，不能把重新安装或升级当作必然修复。


空页只代表本次没有取回岗位；“未读取到薪资”也不等于面议。工作台已跳过 CLI 搜索缓存，仍缺失时需要核对上游返回，不能编造薪资或批量补抓详情。


其他连接问题
提示「找不到 CLI」或「CLI 未就绪」
确认终端中 boss --version 能运行。安装后重启工作台；若仍找不到，请按项目 README 配置 CAREER_BOSS_BIN 为 boss 的实际可执行文件路径。
浏览器没打开，或找不到 Chrome
先确认已安装 Chrome。macOS 可在工作台所在文件夹双击「连接BOSS浏览器.command」。Windows 命令使用默认安装位置，如果报路径不存在，请用你电脑上 chrome.exe 的实际位置替换命令开头。
提示未登录或找不到浏览器会话
按第 2 步打开专用窗口，再在该窗口中登录 BOSS。不要仅在原来的日常 Chrome 或手机 App 中登录。专用窗口需一直保持运行。
提示账号风险、验证码或读取受限
请按上方平台风险排障指南区分平台拒绝与本地风险锁。工作台不会自动清锁或重试。
搜索很慢，或岗位详情已失效
一次请求最长约 45 秒，同一工作台同时只运行一项 BOSS 请求。超时后可手动重试；详情失效时，重新搜索该职位获取最新信息。上游页面变化也可能导致工具暂时无法读取。


哪些操作由你完成
登录与验证码、联系招聘者、发送消息、上传简历及正式投递，都在原平台完成。
工作台负责按次搜索、保存机会、本地匹配、准备简历和记录进度。导出 PDF 不会自动投递。
使用结束后可关闭专用 Chrome。未连接 BOSS 时，简历编辑、手动添加岗位、机会管理与薪酬测算仍可使用。
