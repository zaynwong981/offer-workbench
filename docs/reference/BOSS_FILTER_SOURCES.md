# BOSS筛选与通用偏好依据

整理于2026-11-24；这是离线参数快照与适配说明，不代表实时岗位结果已验收。本轮未访问招聘账号、清除风险锁或执行搜索。

- 城市名称／编码事实表：公开[city_codes.json](https://github.com/OpsDJ/boss-scraper/blob/master/data/city_codes.json)，读取blob `419006f8520d1069ed708bf2b001ffc3349b80a7`；只整理大陆城市及香港的名称、编码事实，排除全国、澳门、台湾及东沙群岛，370项。香港为101320300；如有平台调整需更新快照。不包含该项目的抓取逻辑。常用城市与本机boss-agent-cli 3.0.1表交叉核对。
- 经验编码：公开[平台条件表修正说明](https://github.com/eatmoreduck/boss-zhipin-scraper/issues/3)列明102应届、108在校、101经验不限、103一年以内、104一至三年、105三至五年、106五至十年、107十年以上。CLI 3.0.1内置中文映射存在错位，本适配器通过其现有`--url`白名单传递明确编码。
- 薪资参考[公开筛选参数说明](https://www.typingmind.com/skills/eatmoreduck-boss-zhipin-scraper)：402三千以下、403三至五千、404五至一万、405一至两万、406两至五万、407五万以上。偏好可手填，不要求恰好落入平台区间。旧10–15K搜索方案保留显示，但执行前要求重选，不静默扩大到10–20K。
- 行业名称及编码、实习类型依据独立安装的[boss-agent-cli 3.0.1](https://github.com/can4hou6joeng4/boss-agent-cli) `api/boss.yaml`、`commands/search.py`、`search_filters.py`。CLI实习请求1902并对响应实习枚举4再过滤，不能用它代替校招。

校招按experience=102筛选；社招按101及103–107缩小范围，可再选具体年限；实习使用CLI的`--job-type=实习`。这是普通职位搜索条件，并非切换到校招专区，也不保证结果排除所有其他招聘渠道；最终届别、在校身份和报名资格需核实。多条件矛盾时执行前报错。

岗位与业务分类是为通用求职整理的两级目录，不声称完整复刻平台岗位树。岗位方向填入关键词；目录内业务使用行业条件，自定义业务词并入关键词。每次只提交一组城市／方向，不自动遍历所有偏好。

城市URL由后端生成，只接受目录内名称；不接受用户传入任意URL或原始编码。无匹配时拒绝执行，不回退全国。城市目录不代表每个城市均有在招职位。香港岗位币种需另行核实，五城人民币薪酬／个税估算不适用于香港。
