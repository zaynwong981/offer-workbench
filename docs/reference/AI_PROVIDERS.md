# AI接口与数据边界

核对日期：2026-11-24。接口文档是实现依据，真实账号连通性、模型权限、额度和地区由用户自行测试。本版自动验收使用模拟响应，没有复用本机密钥或发送个人资料。

| 服务商 | 默认Base URL | 协议与官方依据 |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | [Responses](https://developers.openai.com/api/reference/resources/responses/methods/create)，关闭服务端响应存储的请求参数为`store:false` |
| Anthropic | `https://api.anthropic.com/v1` | [Messages](https://platform.claude.com/docs/en/api/messages)，独立system字段、x-api-key与可配置anthropic-version |
| DeepSeek | `https://api.deepseek.com` | [Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)，Bearer认证、messages与max_tokens |
| 自定义 | 本人填写 | 可选以上三种协议；Base URL填写到版本路径，工作台追加相应请求路径，不重复填写responses或chat/completions |

模型ID由本人填写，以服务商控制台实际开放情况为准，不把固定模型名冒充当前账号可用模型。自定义地址使用HTTPS；本机HTTP需要显式允许，支持localhost、127.0.0.1或::1。请求不跟随重定向，不自动重试，45秒超时。没有模型工具调用、文件上传或后台抓取。

## 发送与预算

保存配置不发请求。每次先生成本机发送草稿，展示目标地址、模型、所选JD、素材与单个简历段落，确认后只发送这份快照。预览30分钟有效且只能发送一次；配置变化需重新预览。固定连接测试只发送测试指令，不包含材料。

不自动附带个人资料、照片、其他简历或岗位。但所选正文可能包含个人信息，发送前仍需自行核对。关闭AI后手工编辑、素材库、JD本地统计和复制提示词均可使用。

每次按输入UTF-8字节数保守估算Token，再加输出上限，预留本机每日预算；失败也计入请求数和预留量，不把超时认定为免费。每日按北京时间累计。显示服务商返回的Token使用字段，不进行固定人民币估价。预算不是服务商账单，也无法控制用户在其他工具中的消费。

## 密钥与备份

密钥只写入数据目录下`.secrets/llm.json`，POSIX目录700、文件600；Windows还需使用自己的系统账户权限。服务端仅返回是否已设置，不回传密钥。切换服务商或Base URL会清掉旧密钥。明文只用于本机受限存储和HTTPS认证，并非操作系统钥匙串加密。

密钥不进入浏览器存储、日志、Git、源码包、普通求职备份或升级快照。换机或恢复后需要重新填写。已有本机密钥不会因为导入求职备份而替换。

## 证据与修改

素材保存来源与待核实／已核实状态。模型结果不是事实证明：引用原句必须在本次所选素材或JD中找到；改写出现原段落或已核实素材中不存在的数字时拒绝直接采纳。数字检查不能证明所有语义真实，仍需本人核实职责、成果与确定程度。

每次只处理一个段落，原文和建议并排展示，可手动调整，再勾选已核实并采纳。原段落已变更时拒绝覆盖；撤销也要求内容与采纳时一致。原始结果、来源快照、失败原因保存在本机草稿；从备份恢复的草稿仅供参考，不重放授权或直接改简历。
