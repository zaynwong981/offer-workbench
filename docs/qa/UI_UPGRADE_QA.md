## 设计技能的适用范围

Kind：software。Palette：用户明确要求的简约蓝调（#245bcc / #172b46 / #f5f7fb / 白色）；字体为系统中文无衬线。
Voice：直接说明动作、保存结果、操作步骤与能力范围；保留原业务文本。
Hero、随机配色、shader、scene、dealt moment：本次不采用，因用户要求紧凑业务页面、保留业务功能及现有导航。没有引入图库素材、虚构业务数字、宣传文案、占位联系人、云表单或外部 canonical domain。现有照片与资料始终属于本机用户内容。

剩余 18 项不是正式 waiver，也不表述为门禁 PASS。用户的业务要求优先于技能的宣传站默认结构，逐项保留原因如下：

## 产品边界

- BOSS 手册仅说明连接操作；本次未执行登录、搜索、投递、消息发送或简历上传。

- Windows/Linux 仅提供操作说明，未新增跨系统实机验收；远程 CI 未在本次执行。
- 个人数据、截图、PDF、浏览器验收夹具与本地配置不进入源码包。
