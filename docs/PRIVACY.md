# 公开发布边界

本产品源于真实用户旅程，公开代码只包含可复用逻辑和重新合成的测试资料。测试姓名、教育、公司、时间和岗位均为示例，不是作者真实履历，不代表有效职位或能力成绩。

- 白名单控制打包与 Git 跟踪文件，不能只依赖 .gitignore。
- `scripts/privacy_check.py` 检查白名单和实际 Git 跟踪文件，拦截私有目录、绝对主目录、私有飞书链接、常见密钥及真实手机号格式。它是自动门禁，不是完美 DLP；首次公开及新增素材仍需人工逐文件检查。
- 浏览器／本地数据、配置、历史备份、照片、PDF、聊天记录、平台缓存、Token、API Key 禁止进入仓库和 Release。git 提交身份采用项目署名和无真实邮箱；GitHub 账号本身仍然公开，不能承诺账号匿名。
- 公共演示由 `scripts/demo.py` 从零生成；拒绝覆盖已有目录，不读取用户数据。
- 如果历史提交意外泄露秘密，仅删除文件或 revert 不足以消除历史；撤销秘密、停止发布，再按 GitHub 指南清理历史。不要用 force push 覆盖未知远程历史。

0.8.0 可选 LLM：用户选定内容后才可发送；本地后端保管密钥，禁止返回到前端或普通备份。连接测试仅发送固定文字。真实账号连通性需本人测试，未自动发送个人材料；普通备份与升级快照不包含密钥。

0.7.0求职备份包含实际PDF、个人信息、简历正文、岗位与沟通材料快照。它们仅存本机，但备份并非脱敏文件，不能上传到Issue或公共仓库。前端会话草稿仍受浏览器存储限制，正式保存与备份由用户操作。
