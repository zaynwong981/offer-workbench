# 用合成案例体验

以下素材仅借鉴“金融＋技术背景、三个产品方向、在职探索”的通用场景。姓名、公司、教育、薪资和安排全部虚构；不包含真实工作记录或照片。

```sh
python scripts/demo.py --data-dir demo-data
python server.py --port 8767 --data-dir demo-data --export-dir demo-exports
```

打开 `http://127.0.0.1:8767/career#calendar`。月历切到 **2026 年 11 月**，查看 25 日两个活动重叠和作品集 DDL 提示。也可编辑时间到你希望演示的月份。演示数据与个人 data 完全隔离；再次生成请用新的空目录。

| 用例 | 操作 | 应看到的结果 |
|---|---|---|
| 三方向简历 | 简历页切换 SaaS／AI／金融方向 | 虚构文本和姓名，可人工编辑、预览PDF并检查页数 |
| 岗位准备 | 打开示例云软件岗位→复制岗位专属版本→编辑→导出 | 原母版不变；导出后状态仍不是已投递 |
| 筛选与取舍 | 设置深圳SaaS偏好，将岗位标为稍后考虑 | 偏好可填入搜索，取舍不改招聘进度 |
| 投递留档 | 岗位导出PDF后确认实际使用文件、渠道与时间（仅演示） | 后续改简历仍能查看旧PDF；导出本身不投递 |
| 笔试冲突 | 11 月 25 日 14:00 面试、14:30 笔试 | 两个活动明确提示时间重叠 |
| DDL | 同日 14:45 作品集截止 | 提示截止点落在活动中，不当成全天占用 |
| 修改时间 | 把笔试改为面试结束后 | 不再提示两者重叠，DDL 警告仍按实际安排计算 |
| 待定通知 | 勾选仅知道日期 | 展示时刻待确认，不猜具体时间 |
| 备份／恢复 | 导出求职备份，再在另一隔离数据目录导入 | 岗位、日程、关联、历史可恢复 |
| 可选平台不可用 | 不装 BOSS CLI | 手动岗位、简历、日历和薪酬仍可用 |

项目简历表述可参考：“基于求职过程中的多端搬运问题，设计并实现本地求职工作台，覆盖多方向简历编辑、PDF 导出、岗位跟进与多事件日历；建立隐私隔离、合成测试、Git 版本和备份恢复流程。”发布／测试通过后再补充可核实的链接与数量，不写未经统计的效率提升或用户规模。

## 工作流录像

README 的 docs/media/workflow-demo.mp4 为v0.8.4真实Chrome录制，1440×900、H.264、60fps、44.83秒。原始采集2690帧，实测约58.21fps；以每个采集帧对应一个输出帧编码，无插帧或用旧低帧率视频重复补帧。GIF为800px、15fps轻量预览，流畅完整观看请打开MP4。

演示围绕三个问题展开：岗位散落多处→统一收录和分析；简历反复修改→原文对照、确认同步和继续润色；面试笔试冲突→月历与具体时间提示，并展示城市到手收入估算。资料、岗位、薪资和日程全部虚构，AI回复由隔离假模型提供，说明操作而非真实模型质量。没有连接招聘平台、联系招聘者或模拟实际投递成功。录制脚本、浏览器配置与截图不属于产品运行依赖，也不进入公开包。

0.8.1丰富了五组虚构经历与教育背景，按金融科技和AI产品的通用能力组织。英语成绩与“CPA一级通过”为指定的虚构展示占位；后者不是规范考试级别，不应照抄到真实简历。新建工作台为空白，示例不会覆盖个人data。
